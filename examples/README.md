# BurnGuard Pro — Synthetic Benchmark Fixtures

All files inside `examples/` are **100% synthetic benchmark fixtures** generated deterministically by `generate_benchmarks.py` to demonstrate and test BurnGuard Pro's cost and security engines:

- `benchmarks/01_claude_code_runaway_session.jsonl`: Synthetic Claude Opus 4.6 transcript exhibiting a 5-turn failing `pytest` loop, dynamic timestamp prompt-cache busting, 26 eager tool schemas, and an unfiltered 38KB `package-lock.json` dump.
- `benchmarks/02_openai_codex_ci_session.json`: Synthetic OpenAI `gpt-5-codex` session with uncached context and verbose `cargo build` stdout snowballs.
- `benchmarks/03_gemini_agent_session.jsonl`: Synthetic Google `gemini-3.1-pro` session demonstrating MCP tool schema bloat across turns.
- `mcp/vulnerable_mcp_config.json`: Synthetic vulnerable MCP config (fake `SYNTHETIC0BENCHMARK` token strings, unpinned `npx -y`, `/` root filesystem mount, unsandboxed shell runner, plaintext `http://` remote endpoint, and >80 eager tools).
- `mcp/hardened_mcp_config.json`: Auto-remediated safe MCP config output produced by `burnguard audit-mcp --write-safe`.
- `sample-flagship-report.html`: Self-contained offline dark-mode HTML diagnostic report generated by `burnguard report`.
